Shuddy is a scheduling buddy app. 

## Primary Requirements
- Allow for multiple users to combine their schedules in order to easily find times when all parties are free
- Provide an extremely simple UI to block out time slots and compare multiple schedules together with color-coded and textured blocks to make it clear
- Ability to create "Groups" and generate unique group links
- When users receive a group link, they are prompted to provide their name and select a color
- After joining, users are taken to a group dashboard showing the calendar with all members' blocked timeslots
- No login required - users create anonymous profiles when invited
- Google Calendar integration to pull in auth
